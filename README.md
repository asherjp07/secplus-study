# Security+ Study Lab

A self-contained study platform for the CompTIA Security+ (SY0-801) exam: study notes for all 27 objectives, 932 practice questions, 49 performance-based questions, an exam simulator and spaced-repetition flashcards.

Open `index.html` in a browser, or use the GitHub Pages site. Progress is saved in your browser on each device; use Progress → Export/Import to move it.

Questions and notes are original study material written from the public exam objectives. Not affiliated with or endorsed by CompTIA.
